# Hurghada Journeys — Images Stage A

Run `05_INSTALL_REAL_IMAGES_STAGE_A.cmd` from the project root after copying this patch into the project.

Stage A replaces the primary placeholder artwork for the most visible trip groups with locally downloaded Wikimedia Commons photographs and records attribution in `docs/IMAGE_CREDITS_STAGE_A.md`.

Next.js will serve these local images and can optimize them for supported browser formats. Stage B will add more destination-specific gallery photographs and complete the remaining trip imagery.
